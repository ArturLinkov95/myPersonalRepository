# Название фичи:

Кнопка, перемещающая чата в самый его низ

# Как она работает:

Кнопка "v" появляется лишь при скролле вниз (если пользователь скроллит вверх, затем вниз, а затем наверх - кнопка пропадает). 
По нажатии на неё, она пропадает, а чат перемещается к самому своему низу.

# Как она не должна работать:

Кнопка "v" не появляется, если скроллить только наверх.

# Как она устроена

1. В вёрстве (файл index.html) добавил новую кнопку с классом и id "button-down";
2. В стилях (файл style.css) прописать кнопку. Плюс добавил к элементу chatList: "scroll-behavior: smooth" для плавной прокрутки;
3. Непосредственно в самом коде (файл main.js):
 3.1. Создал константу с кнопкой;
 3.2. Навершал на общий элемент блока с чатом (chatList) слушателя по скроллу так, чтобы:
   3.2.1. При прокрутке вниз - кнопка появлялась, а при прокрутке вверх - исчезала;
   3.2.2. Если пользователь уже находится в самом низу чата, кнопка так же должна пропадать.
 3.3. Навешал слушателя по клику на саму кнопку (button-down). Чтобы по нажатии на неё осуществлялся плавний скролл до самого низа чата.
